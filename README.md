# Number Guessing Game

A simple **Number Guessing Game** built using Python. The computer generates a secret number, and the user tries to guess it.

## How It Works

* The computer generates a random number between **1 and 99**.
* The user enters a guess between **1 and 100**.
* The game compares the user's guess with the secret number.

### Game Results

* ❄️ **Cold** — The guess is more than 10 away from the secret number.
* 🔥 **Hot** — The guess is within 10 of the secret number.
* 🎯 **Correct** — The guess matches the secret number.

The game continues until the user guesses the correct number.

## Technologies Used

* Python
* Random number generation
* Conditional statements
* Loops
* User input

## How to Run

Open the Python file and run the program. Enter your guesses when prompted and continue guessing until you find the secret number.

## Project Purpose

This project was created to practice basic Python programming concepts such as functions, loops, conditions, random numbers, and user input.
